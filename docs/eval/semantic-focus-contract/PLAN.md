# Proposed experiment: non-dominated requested evidence must not be erased by semantic focus

Base14064c5. Development; proposal for review, NOT an accepted serving contract.
No production edits, threshold/weight/query/oracle changes or original-pack trials.

## Smallest falsifiable hypothesis

A max-coverage method may rank first, but that count alone cannot justify dropping
an already recalled, source-bound competing file that carries a requested marker
absent from the selected methods. Marker presence is only retrieval evidence.
Keeping that file does not assert it satisfies the full query or owns the result.

Proposed scope: ONLY the semantic-focus branch. Compute the existing selected set
unchanged. For each other path, inspect its existing current-source evidence and
requested marker set. If a bounded actual symbol or source-locatable file has
nonempty requested markers outside the union carried by the selected methods,
semantic focus is not exclusive. Retain the original candidate list without
falling through to a later identity/structural focus that repeats the deletion.
Existing query filters, score order, graph/source caps and diversity remain intact.
Do not inject a path, union file markers into any method, change score or issue an
owner/completeness certificate. This is a recall/precision policy experiment.

Unknown validity, missing bounds or untyped evidence do not establish marker
absence and cannot certify exclusive completeness. The initial experiment must
retain baseline behavior for those inputs rather than invent a proof. Passing this
experiment would not validate existing focus decisions in unknown inputs.

## Why this is not a false unification

Visual: Stack/overlay and backgroundColor are alternative layout evidence. The
veto preserves a distinct requested mechanism; it never says the entire marker
list is conjunctively required, or that backgroundColor is intrinsically superior.
Lifecycle: file evidence may record lifecycle sync while an individual competing
method covers state/write only. Retaining its path does not aggregate those methods
into a proven lifecycle chain. Split classes and deferred calls cannot gain new
method coverage or a unique-owner label.

These two negatives can test the SAME non-erasure policy. They cannot validate a
shared positive ownership proof. If preserving alternatives produces too much
noise or wrong localizer output, this hypothesis is falsified as a useful repair;
do not then tune scores, enlarge excerpts, add query keywords or change expected sets.

## Alternative not selected for this stage

Typed aggregate representation would need owner ID, exact method IDs/ranges,
per-method roles, call/receiver links and unknown closure. It could eventually
express lifecycle requirements, but does NOT solve visual alternative semantics.
It changes producer/schema/consumers and requires new scope/dataflow evidence.
It is not the smallest test and must not be smuggled into the retention experiment.

## Frozen controls and acceptance

protocol.json preserves the two original independent families and declares source,
query and required/forbidden source identities before public execution. Existing
strict red expectations remain strict. Supplemental controls cover literal text,
actual two-operation method, same-file split classes, duplicate owner names, true
logs, explicit single and multiple identities. No claim of a unique owner is made
from these source sets. Existing broad families' inherited precision failures must
remain failures, not expectedFailure conversions.

Stage-level controls (not new public semantics): missing/old/unknown source record,
invalid range, repeated IDs, non-code markers, nested deferred bodies must not gain
new source-operation or method proof; no fields except selected-set behavior change.
Token budget1500, unchanged selection scopes, source caps, log/path preservation,
and all explicit targets remain required. Public output with a retained target but
an extra forbidden source is still red; raw-only recall gain is not success.

Run baseline first, commit frozen protocol+results. ONLY after review run isolated
candidate. Compare full source sets, actual excerpts, provenance/certificates and
budget, not just overlap. Run existing method focus, owner contracts, adjacent
collection, lifecycle cleanup, source-op, multi-target and graph/log regressions.
Acceptance requires the two independent generic reds green and no new regressions
in frozen controls or relevant existing tests. Stop if either still red. Original
pack is not a parameter-selection source and is not run during this experiment.
