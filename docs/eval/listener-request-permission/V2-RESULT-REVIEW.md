## What remains unverified for formal production

Per-witness validation is much narrower and clearer than v1: exact nested fields,
version/unit, signature/formal identity, key/path/range/digest snapshot joins and
nested offsets. Source-time extraction verifies supported source shape. Decoder
explicitly trusts provider-attested inner source facts; without bytes it does not
reparse them. The explicit test acknowledging that boundary is not a bug or a
claim of source authentication.

The optional batch list has no explicit total count/byte cap or duplicate witness
identity rule before iteration. Per-file prototype/method caps and4096 persisted
side packing do not bound arbitrary decoded batch input. Validator does not require
entity.kind to be a callable; a crafted entity with a callable-like signature can
pass those shape checks. These are static untested formalization gaps, not results
from newly run counterexamples. Require separately frozen total-list/duplicate and
noncallable entity controls before production. An exact duplicate should not
consume arbitrary capacity; conflicting same-identity facts need explicit handling.

Snapshot_length/outer offsets are provider claims checked for shape/containment,
not recomputed from bytes by decoder. That is acceptable only when the trust
boundary is documented, and byte digest versus normalized decoded coordinates
remains explicit. Current subset overlength test does not establish every encoding
or newline conversion. Source runtime adapter/legacy migration paths beyond this
temporary overlay and old-reader rejection policy need production integration
review. Do not call it schema-free or transparently backwards readable.

Verdict: accept v2 as a successful isolated compatibility experiment with stated
limits. Do not yet grant formal production integration or selector authority.

## Worthwhile next finite request experiment

mapping and worth a separately frozen offline experiment. Define a descriptor
with named type, explicit relation kind and exact case-preserving invoked member;
callback property is separately explicit or unspecified, not inferred equal to
member. The independent phrase DeliverySink rejected contract may be considered
only under an independently specified relation grammar and reviewed attachment.
A grammar should express relations, not fixed word counts or original verbs alone.

quoted instruction, negation, wrapper/caller, return/declaration, two types, two
members, multiple forwarders and unknown attachment. Unknown does not discard
sources or grant unique/bounded primary. Test descriptor only, no source ranking,
new public queries or original oracle changes. If accepted later, matching must
consume validated identity-bound facts rather than old lexical weak flags.

be compared as an identifier without identifier_tokens('rejected'), which is empty.

on-prefix/synonym rules to do so. Neither model feasibility nor descriptor tests
