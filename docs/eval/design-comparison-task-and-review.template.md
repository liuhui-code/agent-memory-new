# 设计对照：任务与评审工作表

模板日期：2026-11-18。使用约定见 [P2 合同](../design-comparison-preparation.zh-CN.md)。
这是人工/Agent 填写的工作表，不是 Runtime JSON 输入。空白、unknown 和未签定项均不算通过。
真实任务正文及产物留在受控保管处；复制本表到保管处填写，Git 只保留无私密内容的摘要和引用。

## 活动封面：首个任务到达前填写

| 字段 | 冻结值 / 可核验引用 |
|---|---|
| 活动 ID、负责人、授权范围与起止 | 待提供；本模板不授权执行 |
| 真实项目、任务来源、连续性负责人、开始点 | 待提供；不能用 M1/P1/生成题替代 |
| 固定 presented 数量 | 待冻结；排除项也计数，不补题 |
| 排除原因、设计子集和配对条件 | 待冻结；含非设计/重复/无法配对等的具体判定 |
| 配对选择、容量、顺序与重复次数 | 待冻结；执行前选定，不能看答案选择 |
| A/B/C Runtime / Skill / 共同资料摘要 | 待绑定；A 为现有 Skill 基线，不是裸 Agent |
| C 任务前 Memory、A/B 无历史底座、增量清单 | 待绑定；共同源码/规范/通用目录一致 |
| 模型/参数、宿主版本、工具权限及全局资料隔离 | 待冻结并验证；不能仅记录产品名 |
| 相同初始提示与调查规则 | 待冻结；处理差异仅按合同表 |
| 每组时间/Token/源码/查询/修正预算及可接受成本 | 待冻结；查询与验证包括在总成本内 |
| 基础设施重试、预算退出、缺失/漂移处理 | 待冻结；保留原失败，不 optional stopping |
| 端到端计时/完整工具事件/Token 的实际采集方式 | 待验证；缺失记 unknown 或配对无效 |
| 原始资料保管位置、保管人、访问/保留/删除规则 | 待指定；不进入 Memory SQLite/Git |
| 任务验收人、独立评审人、异议复核及盲法限制 | 待指定；作者自审不计独立评审 |
| 总体、设计子集、历史机会子集的汇总规则 | 待冻结；小样本仅描述，不合成品味总分 |
| 活动启动审查结果 | no_go；不能用此表调用 diagnosis cohort |
