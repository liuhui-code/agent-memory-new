# Frozen source operation admission experiment, 2026-11-14

Two independent defect classes: executable capability checks and lifecycle
persistence reads lose source-operation evidence to lexical descriptions.

Producer: record separate source_operation:<marker> callable roles, never infer
proof from method token strings. Reuse existing runtime API and persistence read
recognizers only after string/comment masking and fail-closed nested callable,
regex/slash and template boundaries. Existing APIs/weights stay unchanged.

Consumer: no numerical bonus. Permit unique-source precedence only when an
existing behavior concept requests that validated operation, the request targets
source rather than literal/declaration/metadata/settings text, no quoted literal,
no explicit named competing target, no existing typed contract, no multiple scope,
and exactly one eligible current callable. Keep >=2 behavior focus unchanged.
No new candidate recall, cross-file portfolio or scope classification permission.
The same witness supplies boundedness; otherwise lexical ranking is unchanged.

Controls: real source API vs string/metadata; typed and exact targets; ordinary
string/manifest requests; source-plus-declaration request; two real source methods;
comments, templates, regex and nested callable counterexamples; restore read/write
and two-owner controls. Existing restore conjoined queries may remain unchanged.
Any regression or unprovable source ownership stops the candidate, not the tests.
