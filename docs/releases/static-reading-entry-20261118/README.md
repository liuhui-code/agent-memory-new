# Finite non-exclusive static reading entry (new capability)

This is an authorized new terminal presentation capability, not a ranking bug fix or original33 precision repair. It supports a closed family of positive scan-implementation requests and a finite clock-field Map scan source shape. No file/owner/method names are hardcoded; captured identifiers must agree through interface field, Map write, capacity check, traversal, minimum comparison, selected key and delete receiver. It proves static syntax and identity only, not runtime Date/Map behavior, global oldestness, unique implementation or causal diagnosis.

## Contract and compatibility

The hook runs only after completed compact rendering in the CLI command handler, before serialization/accounting of that final output. No new primary re-enters retrieval, focus, source allocation or graph consumers. Raw CLI never invokes it. Internal compact_context callers retain their prior semantics.

Admission requires an existing ordinary primary/alternative, exact unique current indexed owner/method identity and digest/generation, whole supported source, and complete matching displayed method bytes. An explicitly tagged semantic_mechanism_window may lie within that one proven method; its candidate range is not expanded or changed. Unauthenticated identities, unsupported/missing source, multiple source-proven targets, incomplete display, protected active path/identity or insufficient budget all preserve the identical baseline object. Count all source-proven candidates BEFORE checking display completeness: an undisplayed second proof still prevents migration.

The candidate array is strictly permuted; no candidate field is added, deleted or overwritten. Evidence-level certainty is uncertain. `boundary=nonexclusive_static_clock_scan_reading` marks the new presentation meaning. `reading_basis.prior` lists indices into the new `[primary, *alternatives]` array in the old ranking order, so original order is exactly recoverable. Uncertified candidates are unresolved, not declared irrelevant or supporting by inference. The source witness is not a source_operation or global ranking authority.

Request surface: complete Locate/Find/Return commands for executable eviction scan ownership, timestamp scan and delete implementation, or minimum-field scan and key deletion source; optional lower-case cache observation carries no source identity. Explicit named methods, FIFO, literal/text/generation, diagnostic/log and mixed/negative requests do not gain this capability. This is NOT general natural-language role understanding.
