# Opt-in callable envelope display (new bounded capability)

This is additive source presentation in explicitly requested `--compact --preserve-selected-source-anchors` mode, not a target-selection fix. After all existing budget allocation and static reading-order processing, an existing callable's authenticated full method range may expand a single existing mechanism excerpt when the whole payload still fits. No new candidate, removal, reorder or semantic role decision is made. Internal compact callers, raw output and default compact behavior remain unchanged.

Qualification binds unique method and owner symbols, typed record identity, indexed complete bounds, file digest, index generation and exact existing source bytes from one bounded read. A mechanism-window candidate is not accepted as full method identity. Unknown shapes, conflicts, absent identity, stale source, malformed content, over-limit or over-budget trials return the unchanged object. Source limits remain40 lines/1500 characters per envelope and2600 total excerpt characters. Multi-item attempts follow unchanged anchor order and never discard another item to make room.

Old excerpt metadata is stored in `expanded_from`; the old content is exactly recoverable as its line interval in the expanded content. `symbol`, range, selection_reason and truncated describe the new actual method; all candidates, scores, uncertainty, graph, logs and other excerpts remain unchanged. No displayed body is persisted by this helper. Existing final redaction applies as before.
