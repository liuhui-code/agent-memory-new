Complete reference-shaped ASCII identifier/dot-chain interpolation bodies qualify, with space/tab/CR/LF whitespace. This lexical property does not imply runtime purity: getters, proxies, template coercion and outer tags can execute code.

All shared default callers retain existing behavior. Any unsupported or malformed interpolation retains the whole-file legacy result. Real interpolation calls remain unsupported and preserved rather than erased. The original candidate stream, order, deduplication, cap and output schema remain unchanged.
