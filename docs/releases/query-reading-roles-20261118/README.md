# Query consumer: reading targets and supporting evidence

This change clarifies the existing Agent CLI Skill. It does NOT introduce supporting_code_anchors, move JSON objects, change Runtime code/ranking/budgets, or make original13/32 acceptance pass. The default context command and its consumer fields remain compatible. No installed user Skill is overwritten by this repository publication.

The practical defect is an ambiguous instruction: the Skill says inspect role=primary first, but Runtime assigns that role by bounded list position, including log-derived callers. New reachable guidance explicitly separates exploration priority from requested ownership. It tells the Agent how to use current source and the request, preserve both target and supporting evidence, handle unknowns and give appropriately typed feedback. Source kind is not an automatic inclusion/exclusion rule.
