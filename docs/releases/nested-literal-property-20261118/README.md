## Scope

Existing symbol keys, flat qualified identities, owners, signatures, ranges and behavior/string evidence remain unchanged. Existing databases gain an unknown NULL value until relearn; relearn clears unsupported or stale facts. No alias registry, runtime-property resolution, new owner/call authority or behavior marker is introduced.

The lexical consumer recognizes a complete `Locate Root.property.callback.` request (also a backtick-marked path), not arbitrary prose fragments. It can reorder only already-selected candidates with equal protected priorities, complete selected-file pools and a bounded current-source check. It does not add recall, change scores or selected membership, cross specialized protection, or raise ordinary certainty solely from the path. Unsupported, ambiguous or stale inputs retain legacy behavior. Scanner and source checks are bounded; defaults and the1500-token budget are unchanged.
