# R plus finite source-consumer proposal, not implementation approval

The original thirteen inputs and final criteria remain fixed. R failure is kept:
discarded-return changed callable evidence, so e864032 cannot ship alone. No-witness
compatibility is measured against the original 39721ec before, not the R after.

## Explicit old pipeline fallback

Add a private allow_render_recall keyword (default existing behavior) to collection
and localization-input transport. False disables only RenderRecall, not Builder
projection, original query, intent gating, negative clauses, custom ports, or old
positive recollection. No recursive context call or global switch. Within context,
first obtain bounded R candidates; before side-effect accounting, attempt source
qualification. If none, unknown identity/guard, insufficient capacity, or any final
binding failure, discard the speculative collection and assemble context normally
from a fresh original-query collection with Render disabled. Localization receives
the same explicit flag so it cannot accidentally mint Render again. Record use and
miss once only. Search has no source consumer and must default to old no-Render
behavior until separately authorized; its new R-only output is not accepted here.

Cost: eligible no-witness requests can run two bounded collections and one bounded
source pass. Do not call this free or promise latency parity. Source bytes maximum
2MiB per file, <=12 already-admitted .ets paths, no directory traversal or new file
search; same-read hash and typed rows must agree. Changed/unknown bytes invalidate
qualification. The subsequent consumer must use the same retained witness bytes,
not reread and silently certify a different revision. Final mismatch triggers old
pipeline, never partial permission. Standard 1500 context budget unchanged.

## Finite whole-file declaration boundary

Refine earlier whole-file shadow/duplicate condition into a closed syntax:
zero or more named imports of ordinary ASCII identifiers from quoted relative paths;
then exactly one @Component or @ComponentV2 export struct IDENT body. No alias,
namespace/default import, extends, extra declarations, overloaded/getter/setter,
function-valued field, unknown decorator, or executable top-level text.
Imports/owner/field names cannot shadow Text/Column/Row/RegExp or helper/build.
Fields may have @State/@Prop/@Param, optional visibility private/public, a unique
IDENT, optional string/number/boolean/plain IDENT type, and a plain string/number/
boolean literal or new IDENT() initializer. Constructor identifier must equal the
plain declared type, not a protected name. No field effects are claimed safe at
runtime; only these syntactic forms are supported. All other top-level owner members
must be exactly the single build and single helper specified in GRAMMAR-DRAFT.
All names unique. Complete import/field/member consumption, not a search for a
convenient method in an otherwise unknown file. The same-file typed owner and both
method identities/ranges/digest/generation must agree with this parsed structure.

Build and helper expression grammars remain those frozen before the public run.
No new regex patterns, return statement branches, or cleanup claims are added.
No persistent edge, generic CFG, source_operation field or global ranking change.

## Selection and exclusion boundaries requiring review

Only components with full positive source witness qualify, non-exhaustively. All
such known positives in the bounded current candidate set must be retained; no
observation NP can force one positive over another. Preserve graph/log/path and
explicit identity protection; if incompatible, use whole old pipeline.

The complete exclusion NP remains in the original AST and is passed unchanged to
existing excluded_code_candidate. It may withhold a positive candidate; it is NOT
new permission to delete every entity or introduce NP/domain aliases. Other
non-positive sources are not selected by this positive source-shape contract,
not certified to match the excluded NP. If this scope is insufficient to honor a
particular full request, fall back rather than discard its tail.

Source-negative discarded, shadow, unknown syntax, two competing positive owners,
identity/digest/range mismatch and copy mutation must be tested prospectively.
The 19 frozen source controls remain unchanged; add explicit closed-file import/
field duplicates and legal @ComponentV2/Param controls before implementation.
Whole old-handoff fallback must be verified with the original thirteen baselines.
Only independent combined acceptance and review can authorize original05 measurement.
