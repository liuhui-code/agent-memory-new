The finite source parser and local non-erasure transport are implemented. Initial 15e81aa source/binding tests ran 15 cases. Helper's final async-header physical-line guard and constructor-name collision alignment were committed separately at 3c89ada, not attributed retroactively to 15e81aa. Independent review found a full-source version issue: comparing only retained class excerpts could miss a new declaration appended after binding. Commit 9334d7a checks complete file digest again immediately before accepting the candidate, with resolved-root and 2 MiB checks; any drift returns the old compact result. This is a best-effort read validation, not a filesystem lock. A tail-appended declaration negative control is retained.

The normal mapping of RecoveryHandoff is unchanged. Copy/deepcopy/JSON remove private authority. Complete original request, original anchors, parsed receipt and source root are bound. No new public marker, recall, producer relation, score, source-range cap or cross-owner injection is introduced. Ordinary private fields use the explicitly revised typed-owner plus parsed-declaration representation, not invented row IDs.

On an eligible request compact construction may run twice: ordinary baseline first, private candidate second. Neither repeats collection or usage recording. The candidate is accepted only when every normal compact anchor is unchanged and ordered, required complete preexisting ranges have matching actual excerpts, log/path/relation fields are exactly preserved, and the actual budget is at most 1500. Otherwise the entire baseline is returned. This extra serialization/source-reading cost has not yet been measured as a performance comparison. Public acceptance has not yet run.
