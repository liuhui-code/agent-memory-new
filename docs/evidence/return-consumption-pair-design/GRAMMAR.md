## Two complete source scopes and exact linkage

Producer complete method, allowing ordinary whitespace/comments between tokens:
`async M(P: string): Promise<boolean | string> { try { await this.F.S(P); return true }
 catch (E) { [Logger.error(T(E));] return T(E) } }`
M/P/F/S/E are ordinary ASCII identifiers. P and E distinct. T(X) is a template
literal containing exactly one `${X}` interpolation, no other expressions or
nested templates; a plain printable prefix/suffix is allowed. Optional Logger.error
is the only allowed additional catch statement; it is not proof logging succeeded.
No finally, nested branch/loop, early extra return, unknown declarations, assignment,
alias, throw expression or post-return statement. Return and expression on same
physical line; whole method consumed. No requirement to prove the external send
throws, network behavior, retry semantics, or complete failure capture.

Consumer complete async onClick callback, inside a current typed component method:
`async () => { const R = await CALL(STRING); if (typeof R === 'boolean') {
 this.H(STRING) } else { this.H(T(R)) } }`
CALL is `this.FIELD.M` with same-component FIELD declared exactly TYPE and
initialized `new TYPE()`, or `this.M` for same-owner producer. R unique and never
reassigned, one await, branches in shown order, H same both branches, no extra
statements/optional/computed calls/aliases/callbacks. T(R) is the direct argument,
not a discarded/intermediate expression. Strings single/double literal; no effect
or truth claim from H's name. H must resolve to the current unique local method;
its implementation may be an empty stub. The registration/enclosing method range
must be current and contain this exact callback. No claim it runs at runtime.

Require active current typed calls AND awaits edges from that exact callback ID to
that exact producer ID, matching receiver/callee spelling, argument arity1, same
project, adapter and evidence source_digest equal to actual caller snapshot. Both
endpoint symbol_key/path/range/digest/index_generation must match current same-read
bytes/file rows. `source_revision=unversioned` alone never verifies freshness;
missing digest/version/kind or stale/multiple endpoint mapping is unknown. Duplicate
method/field/type declarations or unresolved receiver scope are unknown. The source
scanner must explicitly consume/validate relevant declaration scopes, not assume
empty parser gaps certify no shadowing. No edge is created or upgraded.
