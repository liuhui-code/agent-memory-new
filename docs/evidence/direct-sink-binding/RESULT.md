## Final contract and limitations

The new positive receipt requires a plain closed class with exactly two complete
ordinary methods, current typed caller/wrapper/class/sink identity, same source
bytes/digest/generation and existing calls/emits_log edges. The wrapper contains
only legal void-parameter no-ops then one existing canonical sink statement whose
message is a unique declared scalar parameter. A sole this.method caller supplies
a fully parsed, exact-arity argument list; the chosen ordinal must be a complete
simple quoted literal. Parameter position/name is not hard-coded.

Existing sink classification is reused; this work proves a limited message
expression binding, not arbitrary Logger implementation, runtime dispatch, causal
paths, external prototype mutation or generic value flow. New proof is limited
to2MiB, eight parameters and201 physical method lines. Unknown identity, owner,
body, signature, parsing or arity returns to legacy. Only a fully proved structure
and exact argument list with an explicitly nonliteral target returns symbolic.

Thus reassigned/default parameters, complex or aliased wrappers, larger/unknown
owners and other out-of-scope legacy errors remain unresolved. Their old business
literal is not called a newly certified message. No global correctness claim.
