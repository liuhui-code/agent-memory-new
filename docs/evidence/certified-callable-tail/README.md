# Keep a certified same-owner body tail in the first compact response

An uncertain callable ranking can coexist with a certified source interval. The
uncertain return in the compact callable projector intentionally keeps alternate
candidates. That policy is unchanged. But when the ordinary compact source pass
returns one exact excerpt covering the first certified method and the start of
the second, it can stop before the second method's body ends.

Independent Development reproduction: named parcel-dispatch and label-reprint
methods in a non-recognized three-file project. Raw certifies both ranges, 8–13
and 14–19, with uncertain ranking. Before the change, the compact excerpt stops
at 17; the second method's return and closing brace are absent, and the anchor
range ends at 13. Both source and requests were hash-frozen before the CLI run.
The positive and explicit cross-file controls are reproducible with
`tests/test_certified_callable_tail.py`.

The final 1500-token presentation checks existing same-file callable bounds,
a matching selected symbol row for the current index generation and digest,
and callable bounds and the old excerpt in the same snapshot bytes. It appends
only the missing contiguous tail, preserving old content, focus and truncation
metadata. If only the first method had a typed range, the second verified range
is appended to the same file anchor and the read window is widened; this adds
no independent index record or diagnosis. If the byte, scope, shape or budget
checks fail, the exact old response is returned. No existing source excerpts,
anchors, ranking evidence, logs, relations, or uncertainty are displaced.

Observed independent CLI: first response 6–17 becomes 6–19 at estimate
1420→1453, covering both certified methods exactly. Implicit and explicit 1500
agree. In a five-mode before/after comparison on three frozen queries, only
that pair's two 1500 outputs changed. Raw, explicit 2000, preserve 2000,
non-certified wording and explicit cross-file controls were identical.

At unchanged Case 35 source (all 157 retained manifest hashes verified), the
original English response now contains exact 2–15 instead of 2–13, estimate
1459→1479, so the second method is already present without consulting its existing
13–15 read window. The English paraphrase lacks the same-owner certificate and
its simple suffix extension would exceed 1500, so it is unchanged; the Chinese
response already had both complete methods and is unchanged. Neither caller
execution nor an actual Agent source-read or latency reduction was measured.
