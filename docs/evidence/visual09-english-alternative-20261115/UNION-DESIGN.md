# Corrected positive-set proposal, awaiting independent review

The initial stop correctly rejects mapping OR to background alone. It overstates
the old contract when it says unknowns must always be retained: existing09 permits
positive matching source sets without exhaustive/unique ownership claims, skipping
unknowns. The old protocol is preserved, not silently edited. Its unknown-helper
required set is not the proposed positive-set acceptance contract.

Proposed bounded addition:
1. A closed affirmative English request selects either explicit stacking source,
   background styling source, or their OR union. Optional single observation
   noun-phrase covers noun-phrase is not an owner selector. Quotes, negatives,
   AND, identity/path/log/additional tasks are unsupported and fall back unchanged.
2. Existing backgroundColor witness stays unchanged. A separate direct Stack
   witness recognizes the same bounded component/build/UI skeleton. It certifies
   a direct unshadowed Stack constructor outside callbacks, not overlap causality.
3. To preserve genuine Stack with common event attachment, support one finite
   attached onTouch arrow callback form: zero or one optionally typed identifier
   parameter; body zero or more (bounded) this.identifier() statements. No local
   declarations, nested UI, dynamic calls, imports, return values or control flow.
   This is a syntax boundary only; it asserts no behavior about the callback/callee.
   Unknown operations, lexical shadows and unsupported source remain unknown.
4. Recall/retained pool is union of backgroundcolor and stack markers under OR,
   never marker count priority. The positive source witnesses (not marker text)
   determine membership. Complete snapshots of every positive matching owner in
   the unchanged bounded pool must fit existing count/token limits or full fallback.
5. A positive set can omit unknown/nonmatching entries without calling them absent
   or the set exhaustive/unique. No new negative source facts or global veto.
6. Existing source-digest, index generation, owner/method/span, protected identity,
   graph/log/path, copy/mutation, same-read and complete-snapshot safeguards apply.

This changes the source-supported capability set, not just an English alias.
No claim that it succeeds original09 is made in advance. Original09 runs only
unchanged. An independent reviewer must approve these request and source bounds
before serving changes, then review source and focused public results afterward.
