# Scoped default Web-method display budget check

This is a source-presentation change, not a ranking, precision, runtime WebView,
or security fix. It covers only implicit default compact mode. It keeps the
existing response as-is unless already nominated current source proves a single
supported Web chain and one unrelated-by-request wrapped-log method can retain its
complete call while earlier class context remains available via its read window.

Caller, method, class and effect identities and actual old excerpt bytes are checked
against current source and one active index generation. The Web request language is
unchanged. Narrowed excerpt sets its existing truncation field, and its window
includes the earlier class text. Candidate audit keeps all anchors, their order,
log/graph/callable evidence, qualifiers, and other non-display fields. No caller
construction or source relationship is claimed beyond the visible bytes. A source,
identity, ambiguity, time/size or final estimated budget failure leaves the
original object unchanged. The prospective second source read is not included in
the first-response budget or claimed as an observed consumer behavior.

## Independent controls and limit

The prior frozen public Web control records a selected but truncated build on a
separate source shape; that does not demonstrate the complete support transaction.
Four newly frozen offline-manual source files and request reproduce an independent
static Web chain and wrapped logging identities. Their genuine public compact
response (`baseline.json`) instead shows just the help card and does **not**
show the same transaction. It is retained unchanged as a negative outcome; no
noise was added to force a target or consume 1500 tokens.

The separate component suite supplies explicitly controlled display metadata
bound to those four files' actual independent SQLite records/current bytes,
and checks the transaction, evidence equality, rejection of unsupported/log
requests, incomplete/ambiguous/stale evidence, a changed second read, and the
1501 estimate boundary. This is not an independent full public transaction, an
Agent benchmark, a measured reduction in consumer reads, or a closure of case 32.
