# Stage C proposal: finite learned relation hint, then snapshot validation

Design only; changes Stage B's no-index-change assumption explicitly. Sources and all13 queries remain unchanged, and Stage B's bare-request failures are NOT relabeled successful. No implementation until independent approval.

## Existing interfaces and smallest path

1. A finite parser recognizes the already-reviewed direct loop/result grammar. It can parse one complete method and also a complete supported class, returning method ranges and update form (append or overwrite), never a checked-negative for unknown source. No general JavaScript dataflow or unrelated ArkTS marker import.
2. Existing semantic_symbol_evidence.method_evidence_payload already passes the exact typed method source to callable_behavior_hints for both .ts/.ets. Add only collectionfold retrieval hint when this new finite method parser succeeds. Existing roles, other hints and unknown behavior stay unchanged; do not set source_operation:v2.1 or generic exclusive flags.
3. TypeScript summarize_file currently falls through to a plain language/line-count string. For a full-class positive from the SAME finite parser, append only the collectionfold file retrieval hint, allowing the existing file FTS channel to recall a corresponding current file item. ArkTS's existing broader marker list is not tightened or globally transplanted. Both file and method hints are needed because the frozen source-view gate requires already recalled file AND typed method identities. This is a newly declared finite hint projection, not a correction to a previously promised TS mapping.
4. No query expansion or score/limit change. Only requests with BOTH the reviewed original-string relation grammar AND existing behavior_marker_terms containing collectionfold can activate the future view. Bare requests lacking the existing concept remain baseline in Stage C; their Stage B missing-positive results remain unresolved. Contextual-result and contextual-accumulator have the existing concept, as does original26 English.
5. Normal learn-path merge writes the existing summary/method_evidence columns and rebuilds existing FTS. Old index remains baseline until relearn; no schema migration or hidden DB search. Explicit install-before-relearn/after-merge observation must show activation and current source identities. New source hints are retrieval only: the private view still independently reparses full same-read source and validates exact rows/digest/generation/pool/query.
6. Use the already reviewed lossy full-positive-set view ONLY after file+method recall now supplies the bounded pool. Both baseline/trial protections, copy/query binding, final snapshot/complete-body budget and once-only usage remain unchanged. Unknown hints/source do not become negative; explicit unknown targets force baseline.

## Risks and falsification, fixed in advance

The learned hint can affect ordinary requests before a specialized view runs. Required compatibility includes all13 original before requests, named after-loop/deferred/source-text targets and unrelated read/write fixtures. Any undesired control loss is a failure, not excused as 'only retrieval'. No after-loop/deferred/string/shadow/other-return grammar form may receive this hint; direct append and overwrite should. A real converter call only records syntactic item argument use. No runtime correctness or final-value assertion.

Separate recall-only and view stages in evidence. First candidate install without relearn must leave saved index behavior unchanged. After relearn, verify exact initial qualification-hook file+method identities, not merely focus-input inference. If contextual positives are still absent, do not enlarge caps or broaden terms. If recall works but view cannot preserve all supported positives under1500, whole baseline and STOP. Bare-request reds remain open; do not add iteration/accumulator concept aliases to chase them.

This is a finite addition to existing semantic evidence/summary/search interfaces plus an existing-style bound view, not a new generic architecture. Independent review must confirm that classification and the new learn-time scope before implementation. Original26 must be evaluated with its original three variants after controls: English is potentially admitted, generic original/Chinese remain baseline; source span1 alone is not body completeness. No original improvement is assumed from the independent contextual red.
