## Source statement, scope and grammar

Positive statement only: within one complete typed method, a local scalar initialized before a for-of over the method's array parameter is directly assigned inside the loop, and that same lexical local is returned after the loop. The recognized RHS syntactically uses the loop item (or an item property), optionally as the sole argument to a direct this.method call. That last form certifies argument use, not that a callee returns a transformed item. No proof of final-item value, successful execution, runtime scheduling, business authority or unique owner follows.

Finite whole-source recognizer: export class IDENT containing one or more supported methods; method has one array parameter and string return, local let output initialized to a string literal, one for-of (const item of parameter), then return output. Within the loop accept a direct assignment output = RHS, output += RHS, or output = output + RHS. Also accept a single if/else on item.property === string literal with one direct output assignment in each arm. RHS is item, item.property, or this.IDENT(item.property). No arbitrary expression evaluation. All source consumed, no extra class fields/method bodies silently skipped. Additional supported methods can be complete literal-only label methods but cannot supply relation evidence. Exact declarations/tokens/ranges bind parameter,item,output; different/shadowed locals never combine. All statements must be complete under an explicit ASI rule. Comments/strings are lexically masked or tokenized as literal values, not operation syntax.

Unknown: nested callback/function/class, incomplete or extra branch, indirect/computed assignment, break/continue/early return, unknown loops, destructuring, regex, interpolated template, output shadowing, mutation outside recognized structure, additional unparsed declarations, other return target, different methods supplying pieces, malformed source. No positive or absence certificate for unknown. This grammar does not run external converter code and never uses a filename/field name as semantic authority.
