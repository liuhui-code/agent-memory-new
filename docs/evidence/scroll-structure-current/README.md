source-operation v2.1 accepts only runtimecapability and persistenceread; the layout
markers listdirection/scroll/height/verticalaxis are retrieval hints, not a proof
of which runtime viewport the user means. No existing certificate was dropped.

A future narrow experiment would first freeze an independently justified query
representation distinguishing retrieval-instruction metadata from domain terms,
with positive domain requests such as code generation and quoted/code-identifier
requests plus real layout competitors. It must demonstrate that a generic tail
cannot authorize removing a real domain target. There is currently no such
contract; removing `code` globally, increasing layout scores, or treating an
uncertified real Scroll owner as absent is not justified. No terminal-single scope
rule or broad language-only expansion is revived. The precise remaining gap is
localizer task-word attribution, not all stages being blocked.
