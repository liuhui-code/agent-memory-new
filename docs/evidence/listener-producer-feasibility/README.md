## What is and is not feasible

The bounded grammar can construct an explicit source-bound structured witness for
these frozen shapes using existing parsing/masking helpers. The factual name is
**captured_parameter_member_invocation_in_call_argument**. Callback argument names
are checked, but positional value forwarding is not certified. No runtime API
registration, callback execution, runtime object binding or causal delivery claim.

This supports review of a local typed adapter increment, not approval to deploy
this script. It deliberately requires the entire method body to be one member
call/object-argument expression and each property body to be one captured-formal
call. Extra statements, supported-in-language but unmodeled scope or aliases are
unknown. The20 controls do not establish complete language scope/name resolution:
external/import type identity, more elaborate enclosing type shadows, overloads,
parameter defaults and dynamic mutation need an explicitly bounded contract and
further pre-frozen controls before any production proposal. Do not infer that the
existing weak typed-operation request is now strong or that there are two proven
architecture defect classes.

The structure is a local experimental dataclass. Integrating it would still need
explicit semantic-model version/validation/roundtrip compatibility, snapshot joins,
atomic record cap behavior, normal-merge activation and public CLI validation.
There is no free-text detail proof or new current-runtime field here. Consumer
admission and failure/onFailure member selector remain separate unapproved work.
No additional fixture/query tuning or prototype revisions were performed after
this run. A later reviewer counterexample must be saved as a new observation,
not silently repaired into these20 results.
