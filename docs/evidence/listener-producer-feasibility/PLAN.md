No production/schema/query-selector edits. This is an experiment-only typed data
structure and extractor, not a new runtime field. Existing public failures are
stored elsewhere; this run tests source facts and cannot turn them green.

Freeze 20 complete source controls and expected positive tuples in protocol.json.
Relay and Native sources remain exact existing bytes. Other sources are explicitly
pre-execution counterexamples, not adjustments after observing output. Run fixed
inputs once after reviewer checks control scope. Save all failures and stop; no
adding words, altering fixtures or expected tuples to recover a pass.

Supported prototype grammar: known equal-offset ECMA mask; existing parsed unique
module-level class method; simple typed formals (distinct bare types); entire body
is one member call with one inline object argument; properties are explicit arrows;
each arrow body is one exact root formal.member call with callback parameter
arguments. Masked source is used for syntax, original bytes for digest. Unknown,
shadow, mutation, alias, alternate statement or extra nesting emits no facts for
that method. This is intentionally bounded, not general JS binding analysis.

Facts attach outer key/path/range/signature/digest, formal index/name/type,
argument-call interval and chain, object/property/body/invocation intervals and
member. Intervals are decoded characters in newline-normalized adapter text.
No runtime registration, execution, valueflow, absence or unique owner proof.
Property accepted calling rejected is a valid tuple accepted/rejected, NOT a
rejected-property relation; consumers must later apply both selectors.

Prototype only imports existing read-only parsing/masking helpers. It must not
call learn, context or rank; no original query runs. Output is structured JSON,
including skipped/unknown diagnostics and every failed comparison. No changes to
semantic models or persistence, no hidden detail-string protocol. Passing this
matrix only supports further local-model review, not serving promotion.
