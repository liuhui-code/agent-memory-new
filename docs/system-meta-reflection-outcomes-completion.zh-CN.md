- 新模块和 Maintain 参考由现有安装器复制；安装副本用例执行实际失败监测和结果读取。

## 验证依据

[独立用例](../tests/test_system_evolution_outcomes.py)使用临时 Git/归档中的实际候选、验收、文件
应用、监测和回退。窗口数据是合成声明；历史上限的附加行是受控存储元数据，不冒充执行。

| 检查 | 所验证的事实 |
|---|---|
| 只读与隔离 | 数据库字节/表结构不变，非空 query_handoff 一致 |
| 固定绑定 | 篡改/晚绑计划、跨应用/项目输入、重复 JSON 键和超限文件拒绝 |
| 任务分账 | 未知、排除、缺成本与部分窗口保留；拒绝重复身份/序号、布尔成本和额外原始查询字段 |
| 安装及负结果 | 实际监测退出 7 且无产物仍可见；提案维持 applied，不被任务声明改为成功 |
| 漂移与回退 | 实际文件漂移、代码回退、历史操作和 rolled_back 状态不被覆盖 |
| 读取边界 | 未初始化不建归档，历史截断/未决状态是缺口，不推断子进程完成 |

首次加载停在 Python 3.9 注解兼容问题；随后六项中五项因借用含 super() 的夹具方法报错，
一项校验通过。只修复测试兼容和方法绑定，未更改 Runtime 来绕过断言。
修正后的六项通过，耗时 49.466 秒；补充部分窗口及历史边界后，两项定向通过，耗时 32.056 秒。
两次结果覆盖七个不同当前用例，不声称是一次七项整组运行。

完整相关回归保存在[R1 机器记录](evidence/system-meta-reflection/regression-r1-outcomes.json)，
与[此前生命周期记录](evidence/system-meta-reflection/regression-final.json)分开；最终计数和
开始/结束源码摘要以实际进程生成的 JSON 为准。

最终相关批次发现 63 项，62 项通过，0 失败、0 错误；1 项真实宿主用例按显式 opt-in 设计跳过，
不将 skip 记为 R1 宿主验证。测试执行 288.562 秒，记录/清理合计 289.113 秒；这些不是产品性能指标。
Runtime/Skill/测试的开始/结束清单摘要一致；它只证明这两次观察相等，不是冻结或外部认证。

122 个本地链接有效，34 个 Python 文件的项目指纹与 500 行门禁通过，最大 480 行。
git diff --check 通过；规范和 ADR 的批准字段保持空白。
